#In the DocCreator root directory, with docker:

#To build the wheels, for every CPython 3.9 or later of the container:
docker run --rm -v "$(pwd)":/io quay.io/pypa/manylinux_2_28_x86_64 /io/wrapper/python/build_wheels_manylinux.sh

 => the wheels (*.whl) are in the WHEELS/ directory. Each one is repaired
    with auditwheel, installed, and passes tests/python before it is copied
    there.

#For some versions only, give their tags in /opt/python of the container:
docker run --rm -e PYTHON_VERSIONS="cp312-cp312 cp313-cp313" -v "$(pwd)":/io quay.io/pypa/manylinux_2_28_x86_64 /io/wrapper/python/build_wheels_manylinux.sh

#To build with OSMesa (the 3D distortion), with the OSMesa of the container:
docker run --rm -v "$(pwd)":/io quay.io/pypa/manylinux_2_28_x86_64 /io/wrapper/python/build_wheels_with_osmesa_manylinux.sh

 => the wheels are in the WHEELS_OSMESA/ directory.


# Install

Get and install the wheel corresponding to your python version.

You may have to upgrade pip first:
python3 -m pip install --upgrade pip

For example for python 3.12:
python3 -m pip install --upgrade ./DocCreatorPy-1.2.0-cp312-cp312-manylinux_2_28_x86_64.whl


To use it you may have to install pillow & numpy:
python3 -m pip install pillow
python3 -m pip install numpy




# Troubleshootings

- If you have the error:
RuntimeError: module compiled against API version 0xe but this version of numpy is 0xd
 you may have to upgrade numpy:
python3 -m pip install --upgrade numpy
